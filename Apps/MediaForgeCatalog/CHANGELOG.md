# Changelog

All notable changes to MediaForgeCatalog. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions: [Semantic Versioning](https://semver.org/), MAJOR.MINOR.PATCH.

MediaForgeCatalog is an internal developer catalog. It is not shipped. Every merged PR that changes the app bumps the version with `scripts/bump-version.sh mediaforgecatalog patch|minor|major`, which also adds 1 to the build number. Docs-only and CI-only PRs don't bump.
